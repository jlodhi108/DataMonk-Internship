# DataMonk Internship Projects

All work completed during the DataMonk internship, organized into two areas: **Foundation** (core skills modules) and **DevOps** (DevOps tooling projects).

## Foundation

Foundational skills projects, in order:

- [01_linux](Foundation/01_linux) — Linux fundamentals exercise covering core command-line skills.
- [02_git](Foundation/02_git) — Git fundamentals exercise covering version control basics.
- [03_sqlite](Foundation/03_sqlite) — SQLite exercise covering database creation and querying.
- [04_docker](Foundation/04_docker) — Simple CRUD app (Express backend + plain HTML/CSS/JS frontend) containerized with Docker Compose.
- [05_cloud-computing](Foundation/05_cloud-computing) — Google Drive clone with a Node.js/Express backend and a Vite frontend for uploading, storing, and managing files.

## DevOps

DevOps projects, merged in from their original standalone repos (see [DevOps/README.md](DevOps/README.md) for source links):

- [Ansible](DevOps/Ansible) — Ansible playbook that opens TCP port 80 on a remote host using `firewalld`.
- [Ansible_User_Management](DevOps/Ansible_User_Management) — Ansible role-based playbook for managing users on remote servers ([write-up](DevOps/Ansible_User_Management/ansible_final_project.md)).
- [Terraform](DevOps/Terraform) — Terraform IaC that provisions an AWS VPC, public subnet, internet gateway, and EC2 instance.
- [Linting-project](DevOps/Linting-project) — Python project set up with GitHub Super-Linter, flake8, and isort for automated code-quality checks.
- [Python-cl](DevOps/Python-cl) — Python calculator app with a pytest test suite and a GitHub Actions CI pipeline.
